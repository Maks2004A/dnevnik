# Синхронизация тренировок с iPhone

Импорт идёт из календаря iPhone в приложение. Выберите отдельный календарь для тренировок. События в нём должны иметь конкретное время, имя ученика в заголовке и **только номер телефона** в поле «Заметки», например `+7 900 000-00-00`. Имя и телефон должны совпадать с карточкой ученика, если она уже создана.

## Создать команду

1. В приложении откройте **Кабинет тренера → Календарь iPhone → Создать ключ календаря**. Скопируйте ключ для настройки. Каждый новый ключ отключает предыдущий.
2. На iPhone откройте **Команды**, нажмите **+** и назовите команду «Импорт тренировок». Добавьте **Текущая дата** и сохраните результат в переменную `Снимок`. Действиями **Изменить дату** создайте даты `Начало диапазона` (минус 14 дней от снимка) и `Конец диапазона` (плюс 60 дней от снимка).
3. Добавьте **Найти события календаря**. Установите все условия сразу: календарь = ваш календарь тренировок, дата начала в диапазоне от `Начало диапазона` до `Конец диапазона`, событие не на весь день. Оставьте ограничение количества выключенным, чтобы команда передавала все события за период.
4. Добавьте **Повторить для каждого** найденного события. Внутри повтора добавьте **Получить сведения о событиях календаря** для четырёх полей: дата начала, дата окончания, заголовок, заметки. Для обеих дат примените **Форматировать дату → Пользовательский** с форматом `yyyy-MM-dd'T'HH:mm:ssXXXXX`. Последним действием внутри повтора добавьте **Текст** со следующей строкой, подставив переменные вместо скобок.

   ```text
   [Начало ISO]|[Окончание ISO]|[Заголовок]|[Заметки]
   ```

5. Перед повтором инициализируйте переменную `События` пустым действием **Текст**. Внутри повтора после формирования каждой строки используйте **Добавить в переменную → События**. После повтора добавьте **Объединить текст** для этой переменной с разделителем **Новые строки**. Это позволяет отправить пустое расписание, когда в календаре за период нет тренировок.
6. Тем же форматом ISO отформатируйте `Снимок`, `Начало диапазона` и `Конец диапазона`. Добавьте **Получить содержимое URL** со следующими настройками.

   URL — `https://ururcsfneuyjrsvzpnxb.supabase.co/rest/v1/rpc/swim_calendar_import`  
   Метод — **POST**  
   Заголовок `apikey` — `sb_publishable_2fedo6dX3nz4Uh_lghtAmQ_dwBGH_3I`  
   Тело запроса — **JSON**, все поля типа **Текст**.

   | Поле | Значение |
   | --- | --- |
   | `calendar_key` | Ключ из кабинета тренера |
   | `captured_at` | Снимок ISO |
   | `window_from` | Начало диапазона ISO |
   | `window_until` | Конец диапазона ISO |
   | `events` | Объединённые строки из шага 5 |
   
7. Добавьте **Показать уведомление** с результатом запроса, чтобы при тестовом запуске увидеть число обработанных тренировок или сообщение об ошибке. Запустите команду и предоставьте ей доступ к календарю. Откройте приложение и нажмите **Обновить** в кабинете тренера.
8. Для автоматической синхронизации на iPhone откройте **Команды → Автоматизация → Время суток**. Выберите ежедневный запуск, включите **Запускать немедленно** и укажите созданную команду. При переносе тренировки можно сразу запустить эту же команду вручную.

На повторном импорте совпадения определяются по телефону и времени начала. Если будущую тренировку перенести, старая запись отмечается отменённой, а новая появляется на другую дату. Проведённые тренировки отмечает тренер. Ученик получает доступ только после выдачи персонального кода.

См. [создание автоматизации на iPhone](https://support.apple.com/guide/shortcuts/create-a-new-personal-automation-apdfbdbd7123/ios).
