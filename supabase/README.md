# Запуск приложения для плавания

1. В SQL Editor существующего проекта Supabase запустите [swimming.sql](swimming.sql). Миграция создаёт схему `swimming` и функции с префиксом `swim_`. Данные прежнего дневника остаются в прежней схеме.
2. Проверьте, что тренер уже добавлен в **Authentication → Users**, и добавьте его в список тренеров через SQL Editor. Подставьте UUID из списка пользователей.

   ```sql
   insert into swimming.coaches(user_id)
   values ('UUID_пользователя_из_Authentication'::uuid)
   on conflict (user_id) do nothing;
   ```

3. В **Authentication → URL Configuration → Redirect URLs** добавьте `https://maks2004a.github.io/dnevnik/?coach` и `https://maks2004a.github.io/dnevnik/diary.html` для существующего дневника. Сохраните другие разрешённые адреса. Шаблон Magic Link должен использовать Supabase ConfirmationURL.
4. После публикации проверьте вход тренера по почте. Создайте тестового ученика, запишите тренировку и выдайте код. Откройте сайт в приватном окне и проверьте вход с номером и кодом.
5. Подключите отдельный календарь тренировок по [инструкции для iPhone](../swim/iphone.md).

Вход ученика использует номер телефона и уникальный код, который выдаёт тренер. Сервер хранит только хеш кода. Для замены кода или отключения доступа используйте карточку ученика. При смене телефона действующий код сбрасывается автоматически. Повторная загрузка страницы ученика требует входа.
